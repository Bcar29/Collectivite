# Instructions pour installer Inno Setup

## Téléchargement

1. **Sur la page de téléchargement**, cliquez sur **"Current Release"**
2. Vous serez redirigé vers la page de téléchargement
3. Téléchargez le fichier **"innosetup-6.x.x.exe"** (la dernière version stable)

## Installation

1. **Exécutez le fichier téléchargé** (innosetup-6.x.x.exe)
2. Suivez l'assistant d'installation avec les paramètres par défaut
3. Inno Setup sera installé dans : `C:\Program Files (x86)\Inno Setup 6\`

## Vérification de l'installation

Après l'installation, vous devriez avoir :
- **Inno Setup Compiler** : Pour compiler les scripts .iss
- **Inno Setup** : Pour créer des scripts (optionnel, on utilisera seulement le Compiler)

## Prochaine étape

Une fois Inno Setup installé, vous pouvez créer l'installeur en suivant le GUIDE_RAPIDE.md
