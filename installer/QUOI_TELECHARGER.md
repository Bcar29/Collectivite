# Quelle version d'Inno Setup télécharger ?

## ✅ RECOMMANDATION : Choisir "Current Release"

Sur la page de téléchargement d'Inno Setup, cliquez sur **"Current Release"** (version actuelle).

### Pourquoi ?
- ✅ **Version stable** et testée
- ✅ **Version recommandée** pour la production
- ✅ **Compatible** avec tous les scripts fournis
- ✅ **Sécurisée** et fiable

### Version actuelle : Inno Setup 6.6
Cette version inclut :
- Support du mode sombre
- Images PNG pour l'assistant
- Améliorations de l'IDE
- Et bien plus...

## ❌ NE PAS choisir :
- **"Next Release"** : Version en développement, peut être instable
- **"Old Downloads"** : Versions anciennes, non recommandées
- **"Source Code"** : Pour les développeurs uniquement

## Après le téléchargement

1. Exécutez le fichier `innosetup-6.x.x.exe`
2. Installez avec les paramètres par défaut
3. Continuez avec les instructions du GUIDE_RAPIDE.md

## Prochaines étapes

Une fois Inno Setup installé :
1. Préparer la publication : `.\build_installer.ps1`
2. Créer l'installeur : Ouvrir `setup.iss` dans Inno Setup Compiler
